# 🛒 Django E-Commerce - Loja Virtual

![Django](https://shields.io)
![Python](https://shields.io)
![Bootstrap](https://shields.io)

Este é um projeto de **Loja Virtual** desenvolvido em Django para fins de estudo e prática de desenvolvimento web. O sistema engloba desde a listagem de produtos até a gestão de carrinhos de compras e pedidos.

## 🚀 Funcionalidades Atuais

- **Catálogo de Produtos:** Listagem dinâmica com filtros por categoria.
- **Detalhes do Produto:** Página individual com slug amigável (SEO).
- **Sistema de Visualizações:** Contador automático de acessos em cada produto.
- **Carrinho de Compras:** Lógica de adição de itens com controle de quantidade e subtotal.
- **Admin Customizado:** Interface administrativa otimizada para gerenciar pedidos e produtos de forma relacionada (Inlines).
- **Design Responsivo:** Interface construída com Bootstrap 5.

## 🛠️ Tecnologias Utilizadas

- **Framework:** [Django 6.0.3](https://djangoproject.com)
- **Linguagem:** Python 3.x
- **Banco de Dados:** SQLite (Desenvolvimento)
- **Frontend:** HTML5, CSS3, Bootstrap 5.3 e Bootstrap Icons
